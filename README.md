# Mining Production & Predictive Maintenance Intelligence

An executive analytics dashboard for open-pit mining operations: production, equipment, cost, safety, maintenance, and forecasting — with machine learning models for production forecasting, equipment failure prediction, anomaly detection, cost prediction, and ore quality prediction.

## Quickstart

```bash
# 1. Clone and enter the repo
git clone <repo-url>
cd mining-production-intelligence

# 2. Create a virtual environment (Python 3.11 recommended)
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Generate the synthetic operations dataset
python src/data_generator.py

# 5. (Optional) Download the real flotation-plant dataset from Kaggle
#    Requires a Kaggle API token: https://www.kaggle.com/settings -> Create New Token
python scripts/download_flotation.py

# 6. Run the dashboard
python -m streamlit run app.py
```

## Data transparency

This project uses a **hybrid data strategy**, documented honestly:

| Data | Source | Used for |
|---|---|---|
| Mining operations (sites, equipment, production, fuel, maintenance, weather, downtime, workers, cost) | **Synthetic** — generated by `src/data_generator.py` with a fixed seed (reproducible), calibrated against public industry benchmarks | Dashboard analytics, production forecasting, failure prediction, anomaly detection, cost prediction |
| Flotation plant sensor data (737,453 rows) | **Real** — "Quality Prediction in a Mining Process" by edumagalhaes (Kaggle), from an iron-ore flotation plant | Ore quality prediction, process anomaly detection |

The dashboard runs fully on synthetic data out of the box. When the Kaggle CSV is present in `data/raw/`, the ore-quality module automatically switches to the real dataset (the UI shows a "Data: Kaggle" vs "Data: Synthetic" badge). Failure labels in the synthetic data are simulated degradation patterns, clearly marked as such.

## Disclaimer

Synthetic data is realistic in structure but not real operational data. Treat all insights as a demonstration of analytics methodology, not operational advice for a real mine.
